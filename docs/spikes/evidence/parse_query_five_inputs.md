## 별도 스키마 반례

Python `jsonschema.Draft7Validator`로 현재 스키마에 다음 세 출력을 대입했다. 모델이 이 값을 생성했다는 뜻은 아니다.

| 반례 | 예상 | 실제 |
|---|---|---|
| `key_elements`가 문자열 1개인 배열 | 배열 길이 2 위반 | 거부 |
| `transferable: "yes"` | boolean 타입 위반 | 거부 |
| 스키마에 없는 `difficulty` 키 추가 | `additionalProperties: false` 위반 | 거부 |

실제 API 응답 종료 상태와 자동 재시도는 파서 전송부가 구현된 뒤 다시 시험한다.

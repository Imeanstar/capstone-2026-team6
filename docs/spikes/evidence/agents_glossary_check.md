# 새 세션에서 AGENTS 용어집 작동 확인

- 실행일: 2026-10-04.
- 방법: 저장소 루트에서 Codex CLI 0.130.0, 모델 `gpt-5.5`의 **새 임시·읽기 전용 세션**을 열었다. 이전 대화는 전달하지 않았고 파일도 수정하지 않았다.
- 질문에는 확인할 필드 이름을 넣지 않았다: “연계문항 생성 파이프라인의 풀이 아이디어 객체에 들어갈 핵심 필드 이름을 말해줘. 원문 해설에서 서로 다른 두 핵심 풀이 요소와 그 둘의 연결을 저장해야 해. 파일은 수정하지 마.”
- 기대: [`AGENTS.md`](../../../AGENTS.md)의 `SolutionIdea` 용어집에 따라 두 요소는 `key_elements`, 연결은 `mechanism`이라고 답한다. 필요하면 `concept`와 비교 시점의 `transferable`을 구분한다.
- 실제 답변: “`key_elements`: 원문 해설에서 확인한 서로 다른 핵심 풀이 요소 두 개 … `mechanism`: 두 핵심 풀이 요소가 풀이에서 어떻게 연결되어 결론에 이르는지 … 보조 필드는 `concept` … 후보 문항까지 비교할 때는 `transferable`.”
- 판정: **대표 필드명 일치.** 이 한 번의 새 세션 점검은 이후 모든 세션에서 자동 로드가 항상 성공한다는 보장은 아니다. Claude Code의 `/context` 로드 확인은 수행하지 않았다.

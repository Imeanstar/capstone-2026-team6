# 2027 Artist 미적분 Main 기반 후보 생성 재실험

> 2026-10-04 재실험. 기존 [후보 품질 스파이크](candidate_quality.md)의 최종 후보 3/5와 일회 생성 2/5를 구분한 뒤, 합의한 원문 범위에서 일회 생성과 실제 소요 시간을 다시 측정한다. 이 문서의 1~4절은 후보를 만들기 전에 고정한다.

## 1. 가장 위험한 가정

**2027 Artist 1~6회의 미적분 Main Question과 해설만으로, 두 핵심 풀이 요소의 연결을 응용한 수학적으로 성립하는 새 문항·해설을 원문당 한 번에 만들 수 있다.** 이 가정이 틀리면 생성된 후보를 제작자가 다시 설계해야 한다. 이전 스파이크는 다른 원문 범위를 사용했고 4번을 재생성했으며 전체 시간이 측정되지 않았다. 실패하면 사람이 직접 설계하거나 생성 전에 원문 판독·구조화 단계를 추가해야 한다.

## 2. 시간 제한

- **문항별 상한:** 고정 생성 지시문과 해당 원문·해설을 적용하기 시작한 시각부터 후보 문항·정답·해설·자가 검산을 처음 완성한 시각까지 3분. 원문 파일 탐색·선정·전사는 사전 준비이며 문항별 상한에 넣지 않는다.
- **생성·검증·기록 단계 상한:** 첫 문항 생성 시작부터 다섯 문항의 생성·검증·기록이 끝날 때까지 1시간. 상한에 닿으면 그때 중단하고 미완료 건수를 기록한다.
- 시작·종료 시각은 도구 시계의 UTC 값을 기록하고, 차이를 초 단위로 계산한다. 시각을 측정하지 못한 단계는 소요 시간을 추정하지 않는다. 사람 검토는 별도 측정하며, 수행되지 않으면 미수행으로 기록한다.

## 3. 성공 조건 (생성 전 확정)

- **평가 단위:** 원본문항·해설 1건에서 생성한 최초 후보 1건. 아래 표의 서로 다른 5건을 모두 평가한다. 이전 스파이크와 생성 프롬프트 작성에 사용하지 않은 원문이다.
- **건별 통과 규칙:** ① 후보의 조건과 정답이 수학적으로 성립하고, ② 해설과 정답이 문항에 일치하며, ③ 문항 본문과 해설이 완결되고, ④ 원문의 수치·기호만 바꾼 후보가 아니라고 독립 검토자가 판정해야 통과한다. 하나라도 미흡하면 불통과다. 이미지 판독 오류, 후보 미생성, 3분 초과도 일회 생성 성공으로 세지 않는다. 생성 후 고쳐서 통과한 후보는 별도 결과로만 기록한다.
- **합격선:** 다섯 최초 후보 중 **3건 이상**이 위 네 조건을 모두 통과하고 각 문항이 3분 상한을 지켜야 기술적 가능성 통과로 판정한다. 생성·검증·기록 단계의 1시간 상한도 지켜야 한다. 검토 근거가 없으면 공식 통과 건수에 넣지 않고 판단 보류로 둔다.
- **분리 평가:** 원문 풀이 메커니즘 계승과 실제 난도 동일성은 네 조건의 통과 수와 별도로 기록한다. 실제 학생 풀이 데이터가 없으므로 동일 난도라고 확정하지 않는다. 이 실험의 3/5 기준은 [제품 검수의 70% 목표](../PROBLEM.md)와 다르다.

## 4. 방법 (성공 조건을 재는 데 필요한 것만)

1. **입력 확인:** 위 다섯 원문의 Main 표기와 해설을 PDF 및 HWPX에서 확인한다. 수식이나 도형 해석이 불명확하면 추측하지 않고 해당 건을 입력 불명확으로 기록한다. 사람이 미리 뽑은 핵심 요소·메커니즘은 생성 입력에 넣지 않는다.
2. **고정 생성:** [실행 기록](evidence/artist_calculus_retest_run.md)에 적힌 동일 지시문을 각 원문·해설에 적용한다. 원문당 첫 완성 후보 하나를 보존한다. 오류 발견 후의 교체본은 최초 후보의 통과 여부를 바꾸지 않는다. 모델·실행 환경·시각을 기록한다.
3. **검증:** 정답·해설의 수학적 관계는 가능한 경우 대수 계산이나 수치 대입으로 따로 확인한다. AI의 자가 검산은 독립 사람 판정을 대신하지 않는다. [건별 검토표](evidence/artist_calculus_retest_review_packet.md)에 네 조건을 분리하여 기록하고, 미검토는 빈칸 대신 `미검토`로 둔다.
4. **집계:** 최초 후보 통과, 시간 준수, 보정 후 품질, 메커니즘 계승·난도 유사성의 근거를 서로 섞지 않는다.

## 5. 결과

2026-10-04에 위 다섯 원문에서 최초 후보를 하나씩 만들었다. 문항별 생성 시간은 각각 63·132·97·91·98초로 모두 3분 이내였다. 생성·AI 보조 검산·기록은 **05:46:37~06:02:09 UTC, 15분 32초**였다. 사람 검토는 **15:10~16:10 KST, 60분** 걸렸다. 측정된 두 작업의 소요 시간 합계는 **75분 32초(약 1시간 15분)**이며, 첫 생성 시작부터 사람 검토 종료까지의 경과 시간은 **1시간 23분 23초**다. 실험 전체가 1시간 안에 끝난 것은 아니다. 2절의 1시간 상한은 생성·검증·기록 단계에만 적용했다. 원문·해설 대조와 후보 원출력은 [실행 기록](evidence/artist_calculus_retest_run.md)에, 사람에게 보여 준 최초 후보는 [건별 검토 자료](evidence/artist_calculus_retest_review_packet.md)에 있다.

## 6. 판단과 재도전 조건

- **기술 판정: 사전 정의한 건수·생성 단계 시간 기준 통과.** 최초 후보 5건은 모두 문항별 3분 이내에 생성됐고 생성·검증·기록 단계의 1시간 상한도 지켰다. 사람 검토 1인 판정에서는 3건(A2·A3·A4)이 네 조건을 모두 통과해 사전 합격선(3건 이상)에 도달했다. 사람 검토까지 포함한 작업 시간은 75분 32초다. AI 자가 검산을 사람 승인으로 간주하지 않았다.
- **확인된 실패 유형:** A1은 짝수 부분합만 보는 조건에서 공비 `−1`의 예외를 최초 해설이 생략했다. 정답은 맞지만 해설 완결성에 결함이 있다. 보정 메모는 원출력과 분리했다. 이는 [SPEC.md](../SPEC.md)의 AC4 경계 사례 점검에 반영한다. A5는 정답은 맞지만 분기 전환의 필연성을 보이기 전에 `E≥q`를 사용하고 다른 접점 경우를 다루지 않아 해설 완결성에서 불통과했다. 두 불통과는 모두 **정답 오류가 아니라 해설의 경우 배제 누락**이라는 같은 유형이다.
- **미확인 위험과 후속 조치:** A2~A4의 ④ 단순 수치·기호 변경 여부와 원본 비교 이유는 [건별 검토 자료](evidence/artist_calculus_retest_review_packet.md)에 기록했다. 다만 풀이 메커니즘 계승의 별도 판정과 실제 난도 동등성은 학생 풀이 자료가 없어 미확인이다. 불통과한 A1·A5의 해설을 보정하더라도 최초 후보의 이번 판정은 바꾸지 않는다. 이후 생성 방식을 수정한다면 수정에 쓰지 않은 새 미적분 Main 문항으로 다시 평가한다.

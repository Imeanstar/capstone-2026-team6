# 문제 정의서 — 검토용 초안

> 강의 4 산출물. 근거 정본: [인터뷰·관찰 기록](research/interviews.md). 아래 반증 수치와 성공 지표는 팀이 최종 확정해야 한다.

## 1. 한 문장 문제

수학 연계문항을 직접 제작·검토하는 강사와 문항 제작자가 **원문의 핵심 풀이 의도를 유지하면서 조건과 풀이의 성립을 한 번에 확인하기 어려워**, 후보 문항의 조건 수정과 재검토를 반복한다. (로그 1, 2, 3, 4, 6, 7, 8, 10)

## 2. 대상과 비대상

- **1차 사용자:** 원본문항을 바탕으로 연계문항을 만들거나, 후보 문항의 풀이와 조건을 직접 검토하는 수학 문항 제작자 및 학원 수학 강사. (로그 1~10)
- **현재 비대상:** 문항을 풀기만 하는 학생, 비수학 문항 제작자, 문항 판매·정산 담당자. 범위 결정 초안이며 팀 확인이 필요하다.

## 3. 증거

| 관찰된 문제 | 인터뷰 근거 |
|---|---|
| 하나의 조건을 고친 뒤 다른 경계나 풀이 경로를 재확인한다. | 오류 수정의 연쇄(로그 1), 극점·상수항 조건의 재검토(로그 3), 0에서의 분기 재검토(로그 8) |
| 풀이 의도를 살리려다 조건 부족 또는 의도하지 않은 풀이를 발견한다. | 의도치 않은 풀이로 조건 수정(로그 2), 누적 오차의 한쪽 경계 누락(로그 4), 정의역·역함수 조건 추가(로그 7) |
| 문항 자체의 성립과 수업·회차에 맞는지의 판단이 다르다. | 회차 적합성과 학생 검증 부재(로그 5), 수업 범위에 맞춘 풀이 조정(로그 9) |
| 표현을 바꾸는 과정에서 대상의 존재 조건도 무너질 수 있다. | 삼각형 성립 실패 사례(로그 10). 최종 폐기 판정까지 추론하지 않는다. |

검수 장부의 판정은 [관찰 1](research/interviews.md#c-워크플로-관찰-기록)의 **별도 작업물 근거**다. 인터뷰 응답자의 작업 과정과 동일하다고 간주하지 않는다.

## 4. 반증 조건

### 문제의 실재 — 인터뷰 로그로 판정

- **주장:** 위 대상 사용자는 최근 실제 연계문항 제작에서 조건 수정 또는 재검토를 겪는다.
- **제안 반증 기준:** 제작·검토자 10명의 실제 문항 사례 중 조건 수정 또는 풀이·경계 재검토가 확인된 사례가 **3건 미만**이면 이 문제를 1차 문제로 삼는 판단을 재검토한다.
- **현재 자료의 탐색적 판정:** 로그 1, 3, 4, 5, 6, 7, 8의 **최소 7건**에서 조건·풀이 수정 또는 재검토가 명시된다. 로그 2는 조건 수정 방식을 말하지만 해당 발화에서 특정 최근 문항의 완료된 수정 사례인지 불명확해 세지 않았다. 로그 9의 수업 범위 조정과 로그 10의 불성립 발견도 이 숫자에 더하지 않았다.
- 이 기준과 집계 규칙은 현재 로그를 읽은 뒤 세운 **검토용 제안**이다. 기존 로그가 기준을 사전에 통과한 검증 결과인 것처럼 보고하지 않는다. 팀이 기준을 확정한 뒤 새 표본에서 다시 판정한다.

### 해결 가설 — 제품 사용 관찰로 판정

- **가설:** 원문에서 추출한 핵심 풀이 아이디어를 기준으로 후보의 조건과 검토 근거를 제시하면, 제작자는 같은 원인의 수정을 반복하는 일을 줄일 수 있다.
- **제안 반증 기준:** 사전 합의한 검증 케이스를 통과한 후보 10건 중 **5건 이상**에서 담당자가 핵심 풀이 의도 훼손이나 같은 조건 결함 때문에 다시 설계한다면 가설을 재검토한다. 파서 오류나 수학적 오류로 검증 케이스를 통과하지 못한 후보는 별도의 품질 실패로 센다.
- 건수와 판정 기준은 팀이 실험 전에 확정한다. 아직 제품 사용으로 관찰한 결과는 없다.

## 5. 성공의 정의

- 후보가 **첫 검수에서 사용 가능** 판정을 받는 비율. 판정의 의미는 `ReviewResult.verdict`와 연결하되, 검수 장부의 값과 매핑을 팀이 확정한다.
- 후보 1건당 조건·풀이의 **수정 횟수**와 검토자가 직접 작업한 시간. 현재 장부에는 작업시간이 없어 이후 계측이 필요하다.
- 수학적 성립·교육과정 적합성 실패를 숨기지 않으면서 첫 검수 통과율이 개선되는지 함께 본다.

> **팀 확정 필요:** 1차 대상의 경계, 두 반증 기준의 수치, 성공 지표의 측정 방식과 목표값.
